# NeuroScan AI — Research Reports

Generated research PDF reports are saved in this directory (`storage/reports/`).

## PDF Report Contents

Each report compiles:
- Unique research session identifier and processing timestamp.
- Volumetric dimensions, voxel spacing ($s_x \times s_y \times s_z$ mm), and coordinate orientation.
- Model architecture (`3D U-Net`), parameter count, and inference runtime.
- Multi-planar slice thumbnails (Axial, Coronal, Sagittal central tumor cross-sections).
- Quantitative Volumetric Analysis Table (cm³, voxel count, slice extents, connected component lesion count).
- Prominent research and educational disclaimers.

> **Note:** Reports represent computational approximations for academic investigation and are strictly non-diagnostic.
